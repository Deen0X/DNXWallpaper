# Dominios RAG

Un fichero `{dominio}.txt` por area de conocimiento. Registrar cada uno en
`.antigravity/Memory.txt` (seccion 4) para que el bootstrap sepa que existe.

Recomendacion: no crear dominios de golpe. Crear el fichero cuando aparezca
conocimiento real y reutilizable (patrones que se repiten, no estados ni tareas).

Plantilla de dominio:

```
# Dominio: {nombre}

## Patrones
- ...

## Ficheros clave
- ruta:linea -- descripcion

## Gotchas
- ...
```
